# Kontekst Projektu: TECHPARTNER.AI | Ecosystem

## 🎯 Cel projektu
Projekt to ultra-premium landing page dla butikowej agencji doradztwa technologicznego i automatyzacji AI (TechPartner / AI Studio). Głównym celem strony jest:
- Prezentacja ekosystemu usług: od analizy pomysłów, przez automatyzację procesów, po zaawansowaną inżynierię oprogramowania.
- Budowanie zaufania u właścicieli małych firm (uproszczony język, empatyczny chatbot AI).
- Inicjowanie kontaktu sprzedażowego (formularz + chatbot).

## 🛠 Stos technologiczny
### Frontend:
- **Framework:** React + Vite (ESM).
- **Stylizacja:** Custom CSS (Deep Glassmorphism, 60px blur) + Tailwind CSS v3.
- **Animacje:** Lenis, Warp Speed (Canvas), CSS Animations (Pulse Core, Code Cursor, Node Flow).
- **Wizualizacja:** Chart.js + react-chartjs-2.
- **AI:** Google Gemini (1.5 Flash).
- **Assets:** Wyrenderowane grafiki 3D PNG w `/assets`.

### Backend & Infrastruktura:
- **Język:** Go (Golang) – architektura hexagonalna.
- **Hosting:** Vercel (Frontend), GitHub.

## ✨ Aktualny stan (Co już działa)
- **Bento Grid 2.0+:** Pełny układ 6 kafelków z interakcjami: animowany kod (Software), pulsing nodes (Automation) oraz deep glass.
- **Efekty AI Studio:** Globalny filtr ziarna (grain), pulsujące Hero Pulse Core, ulepszona responsywność.
- **Bot Gemini:** Zintegrowany asystent z modelem psychologicznym (reframing).
- **Synchronizacja:** Gałęzie `main` i `master` są zsynchronizowane i wypchnięte na origin.
